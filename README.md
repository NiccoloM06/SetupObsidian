# 🗒️ My Obsidian Setup

A clean, minimal Obsidian configuration for university note-taking.

## 🎨 Theme & Appearance

| Setting | Value |
|---------|-------|
| **Theme** | [Blue Topaz](https://github.com/whyt-byte/Blue-Topaz_Obsidian-css) (dark mode) |
| **Text font** | LMMono12 / LMMono10 / LMMono9 (Latin Modern Mono) |
| **Interface font** | [Inter](https://rsms.me/inter/) |
| **Monospace font** | [JetBrainsMono Nerd Font](https://www.nerdfonts.com/) |
| **Base font size** | 17px |
| **CSS snippet** | `materia-colors` — color-coded folders by subject (Nord palette) |

## ⚙️ Installation

1. **Install the fonts** on your system:
   - [Inter](https://rsms.me/inter/)
   - [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads)
   - [Latin Modern Mono](https://www.fontsquirrel.com/fonts/latin-modern-mono) (LMMono)

2. **Clone this repo** into your vault:
   ```bash
   git clone https://github.com/NiccoloM06/SetupObsidian.git /path/to/vault/.obsidian
   ```

3. **Open the vault** in Obsidian — plugins and theme will load automatically.

4. **Trust the plugins** when prompted by Obsidian.
